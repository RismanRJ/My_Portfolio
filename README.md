# Risman J — Portfolio

3D portfolio of Risman J, Backend Software Engineer (Node.js, Python, AWS). Built with React, TypeScript, Vite, Tailwind CSS, Three.js and Framer Motion.

Based on [ladunjexa/reactjs18-3d-portfolio](https://github.com/ladunjexa/reactjs18-3d-portfolio) (MIT).

## Run

```bash
npm install
npm run dev
```

## Content

- Experience, projects and skills: `src/constants/index.ts`
- Name, hero and about text: `src/constants/config.ts`
- Favicon: `public/favicon.svg`
